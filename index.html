怎么新增一篇笔记

这个站是为「持续新增」设计的：每篇笔记是一个自包含的目录， 主页所有内容由一份清单驱动，加一篇笔记不需要动任何页面代码。

建一个目录

在 notes/ 下新建 <slug>/， 入口文件名必须是 index.html。 目录名用英文短横线风格，它会成为 URL 的一部分。

写你的笔记

目录是自包含的 —— 自己的 CSS、JS、图片都放在里面， 用相对路径互相引用。这样每篇笔记互不干扰， 也不会因为改样式影响到别的笔记。

在清单里加一条

打开 assets/manifest.js，往 notes 数组里加一个对象。 最少只要 slug、title、category、 path 四项，其余留空也不会报错。

提交推送

GitHub Pages 会在 1 分钟内自动重新部署。 统计数字、筛选按钮、分类配色都会跟着清单自动更新。

# 目录结构 frotmo.github.io/ ├── index.html ← 主页（本页） ├── assets/ │ ├── hub.css 主页样式 │ ├── hub.js 主页交互 │ └── manifest.js ← 唯一要维护的文件 ├── notes/ │ ├── speechops-architecture/ │ │ ├── index.html │ │ ├── styles.css │ │ └── app.js │ └── <你的下一篇>/ │ └── index.html ├── .nojekyll 关闭 Jekyll 处理 └── README.md
两个容易踩的坑：
① path 必须以 / 结尾，且不要以 / 开头 —— 用相对路径才能保证以后换域名或加子路径都不用改代码。
② slug 必须与 notes/ 下的目录名完全一致，否则链接会 404。
